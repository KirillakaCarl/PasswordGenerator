PasswordGenerator 1.0.0 / Windows x64

Запустите exe двойным щелчком. Установка Python не нужна.
Храните файлы .vault отдельно от программы.
Мастер-пароль: 12–1024 символа. Восстановления пароля нет.
Создайте хранилище, сгенерируйте пароль и сохраните запись.
Дата в таблице означает дату сохранения записи.
Поиск работает по названию, сортировка — по названию и дате.
Закрытие хранилища очищает поля. Буфер обмена не очищается.
Не открывайте один файл для записи из нескольких экземпляров.
