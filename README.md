# PasswordGenerator

Подготовлена версия **1.0.0** с самостоятельным exe для Windows x64.
Выпуск ещё не отмечен меткой: сначала ручная проверка exe и PR выпуска.
Версия в `main`: **0.3.0-beta.1**, объединена через PR #2.
Первая бета **0.1.0-beta.1** доступна по метке `v0.1.0-beta.1`.
История изменений находится в `CHANGELOG.md`.

Оставшиеся задачи, включая финальную PDF-инструкцию со скриншотами:
`docs/ROADMAP.md`. Порядок изучения кода для защиты: `docs/CODE_GUIDE.md`.

Учебный проект по кейсу № 8: генератор случайных паролей с оценкой сложности.
Программа обучения: «Python-разработчик с использованием инструментов ИИ».

## Текущее состояние

Этап 4: работает генерация с выбором длины 4–128 и групп символов.
Каждый пароль содержит все выбранные группы и не содержит символов остальных.
Есть переключатель видимости, копирование и сообщения об ошибках.
Добавлены автоматическая оценка результата и ручная оценка во второй вкладке.
Добавлено зашифрованное хранилище с мастер-паролем и отдельной вкладкой.
В рабочей ветке добавлены поиск, отображение даты создания и сортировка записей.

Приложение использует cryptography для шифрования и работает локально.
Подключение к Интернету требуется для первоначальной установки зависимости,
но не для генерации, оценки и работы с хранилищем.

## Требования

Для готовой Windows-сборки Python устанавливать не нужно. Распакуйте
`dist/PasswordGenerator-1.0.0-windows-x64.zip` и запустите exe двойным щелчком.
Хранилище `.vault` держите в отдельной папке документов. Ниже приведены
требования для запуска исходного кода и разработки.

- Windows с Python 3.12 или новее и установленным Tkinter.
- Проверенное локальное окружение: Python 3.14.10 (64-bit), Tkinter 9.0.
- cryptography 50.0.2; устанавливается командой ниже.
- Для хранилища используется файловая система с жёсткими ссылками (проверено
  на локальном диске Windows/NTFS). На несовместимом диске создание даст ошибку
  без перезаписи существующего файла.

Виртуальное окружение `.venv` создаётся один раз на каждом компьютере и не
публикуется в Git. Активация окружения необязательна: команды ниже явно
используют Python из него и не требуют менять политику выполнения PowerShell.

## Подготовка и запуск в PowerShell

Откройте терминал в папке проекта. Если команда `python` запускает установленный
Python, создайте окружение:

```powershell
python -m venv .venv
```

На компьютере автора системный ярлык `python` не работает; проверенный вариант:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python314\python.exe" -m venv .venv
```

На другом компьютере путь зависит от установки Python. Проверить его можно
командой `python --version` или `py --version`. Если Python установлен без
Tkinter, добавьте компонент Tcl/Tk через установщик Python.

После создания окружения установите зависимость:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запуск из папки проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

После появления окна его можно закрыть кнопкой «Закрыть» или крестиком.
Проверить установленную зависимость можно командой
`.venv/Scripts/python.exe -m pip check`.

## Как создать пароль

1. Задайте длину от 4 до 128 (по умолчанию 16).
2. Выберите хотя бы одну группу: строчные или прописные латинские буквы,
   цифры, специальные символы. По умолчанию включены все четыре.
3. Нажмите «Сгенерировать». Результат появится скрытым; переключатель
   «Показать пароль» позволяет прочитать его. Длинную строку можно прокручивать в поле.
4. При необходимости нажмите «Копировать» и вставьте пароль в нужное приложение.

Без нажатия «Сохранить» пароли не записываются в файл.
Буфер обмена доступен другим программам и
автоматически не очищается. Новая генерация заменяет предыдущий результат
и снова скрывает его. Ошибка настроек очищает результат и отключает копирование.
Изменение настроек само по себе не создаёт новый пароль: нажмите кнопку генерации.

## Как оценить пароль

После генерации категория и балл появляются под результатом, а пояснения —
во вкладке «Оценка сложности». Там же можно ввести свою строку и нажать «Оценить».
Ввод изначально скрыт; переключатель «Показать ввод» меняет его видимость.
Изменение ввода сбрасывает предыдущую оценку до повторного нажатия кнопки.

Оценка учитывает длину, группы символов и некоторые шаблоны. Порог слабой
категории — меньше 40 баллов, средней — 40–74, сильной — 75–100.
Дополнительные ограничения за короткую длину и шаблоны описаны в
`docs/ASSESSMENT_RULES.md`. Пробелы не обрезаются, Unicode учитывается.
Для пустого ввода предлагается ввести пароль; максимум — 1024 символа.

Это учебная эвристика: она не проверяет утечки, все словари или личные данные,
не гарантирует стойкость и не прогнозирует время взлома. Пароли обрабатываются
локально. Документированное применение ИИ при разработке: `docs/AI_USAGE.md`.

## Как пользоваться хранилищем

1. Во вкладке «Хранилище» нажмите «Создать» и выберите новое имя `.vault`.
   Существующий файл перезаписать нельзя. Введите и повторите мастер-пароль
   длиной 12–1024 символа. Пробелы являются частью мастер-пароля.
   При нарушении требований появится отдельное предупреждение. После него
   можно повторить ввод без нового выбора файла; отмена прервёт создание.
2. Создайте пароль во вкладке генерации либо введите строку во вкладке оценки.
3. Во вкладке хранилища задайте название (1–100 символов), выберите источник
   и нажмите «Сохранить». Пароль записи — от 1 до 1024 символов.
4. Выберите сохранённую запись и включите «Показать», чтобы увидеть секрет.
   Одинаковые названия разрешены, операции различают записи по внутреннему ID.
5. «Удалить» требует подтверждения. Отменить выполненное удаление в приложении нельзя.
6. «Закрыть хранилище» завершает сеанс и очищает поля с паролями и список
   записей. Сохранённые записи остаются в файле; для открытия нужен мастер-пароль.
   Системный буфер обмена при этом не очищается.
7. Для повторного доступа, в том числе после перезапуска, нажмите «Открыть»,
   выберите файл и введите тот же мастер-пароль.

Мастер-пароль не сохраняется и не восстанавливается; его смена не реализована.
Одновременно открывается одно хранилище. Для смены файла сначала закройте
текущий. Операции с файлом выполняются в фоне; до их окончания соответствующие
кнопки недоступны, а закрытие окна откладывается до повторного действия пользователя.

Файл содержит технический JSON-заголовок и зашифрованные названия/пароли.
Не редактируйте его вручную. Размер ограничен 5 МиБ. При неверном пароле или
повреждении выводится общая ошибка, файл не перезаписывается. Одновременная
работа нескольких экземпляров с одним файлом не поддерживается.

Для резервной копии можно скопировать закрытый `.vault` штатными средствами
Windows; встроенного резервного копирования пока нет. Не публикуйте реальные
хранилища в GitHub. Правила формата и ограничения: `docs/STORAGE_FORMAT.md`.

## Поиск, даты и сортировка

В открытом хранилище введите часть названия в поле «Поиск по названию».
Список обновляется сразу, регистр букв не важен. Поиск не обращается к паролям.
«Сбросить» или очистка запроса возвращают все записи. При отсутствии
совпадений выводится сообщение; рядом со списком видно количество результатов.

В списке «Сортировка» доступны название А → Я и Я → А, а также дата от новых
к старым и обратно. По умолчанию первыми показаны новые записи. При равных
названиях/датах сохраняется порядок исходных записей. Русская ё идёт после е;
остальные символы упорядочиваются по Unicode без учёта регистра.

Столбец «Дата создания записи» показывает момент сохранения пароля в хранилище,
а не момент его генерации или создания на стороннем сайте. Дата уже была
сохранена у старых записей, поэтому совместимость файлов сохраняется.
Отображаются локальное время компьютера, секунды и смещение часового пояса.

Поиск и сортировка действуют только на отображение, не меняя файл. При смене
выборки показанный секрет скрывается. При закрытии хранилища очищается запрос
и восстанавливается порядок «сначала новые». Сохранение/удаление сохраняют
активный фильтр: новая запись может не соответствовать текущему запросу.

## Проверка приложения

Проверка синтаксиса и импорта без открытия окна:

```powershell
.\.venv\Scripts\python.exe -m compileall -q main.py password_generator
.\.venv\Scripts\python.exe -c "import main; print('Импорт выполнен без открытия окна')"
```

Автоматические тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Ручная проверка: запустить приложение, изменить длину и группы, сгенерировать
пароль, показать его, скопировать и вставить в пустой редактор. Проверить длины
4 и 128, ввод `abc`, отключение всех групп, изменение размера и закрытие окна.
Используйте только учебные пароли для проверки вставки.
Во второй вкладке сравните `Password123!` и `V7!mQ2#zR9@k`, измените ввод,
проверьте сброс оценки, пустую строку и строку с пробелами.
Для хранилища: создайте учебный файл, сохраните искусственный пароль,
покажите запись, закройте хранилище, перезапустите приложение и откройте файл.
Проверьте неверный мастер-пароль, отмену удаления и подтверждённое удаление.
Для списка: создайте несколько записей с разными названиями, введите часть
названия, смените порядок сортировки, сбросьте запрос. Проверьте отсутствие
совпадений, скрытие показанного секрета при поиске и дату после перезапуска.
Результаты фактически выполненных проверок находятся в `docs/PROGRESS.md`.
