- Загрузить отчёт в «Итоговый проект», видео в «Защита итогового проекта» до 09.11.2026.
- Убедиться, что выполнены промежуточные аттестации для допуска.
- По файлу кейсов также подготовлена презентация. Код, README и инструкции находятся в GitHub.
