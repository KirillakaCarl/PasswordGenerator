# Приложение для итоговой аттестации

PasswordGenerator 1.0.0, кейс 8. Готовая сборка для Windows x64.

1. На странице этой ветки GitHub выберите **Code → Download ZIP**.
2. Распакуйте скачанный архив, откройте папку app и запустите
   **PasswordGenerator-1.0.0-windows-x64.exe**. Python устанавливать не нужно.
3. Создайте отдельное учебное хранилище .vault в своей папке документов.
   Мастер-пароль должен содержать от 12 до 1024 символов.

Исходный код, тесты и описание проекта находятся в корне этой же ветки.
Краткие действия: START_HERE.txt. Сведения о сборке: BUILD_INFO.json.
SHA256SUMS.txt позволяет проверить неизменность exe. Тексты лицензий
включённых компонентов находятся в THIRD_PARTY_LICENSES.

## Результаты проверки и ограничения

47 автоматических тестов пройдены. Готовая сборка прошла встроенную проверку
генерации, оценки, шифрования, сохранения, открытия, поиска и сортировки.
Приложение проверено пользователем на нескольких компьютерах.

На двух корпоративных ПК сохранение вызывало зависание или закрытие окна,
хотя запись сохранялась в файле. На личных устройствах сбой не наблюдался.
Причина пока не установлена; диагностика продолжается в отдельной ветке.
Совместимость со всеми корпоративными средами не заявляется.

Оценка сложности — учебная эвристика без проверки утечек и полного словаря.
Восстановление/смена мастер-пароля и одновременная запись из нескольких
экземпляров не предусмотрены. Используйте искусственные данные для проверки.
