# Ход разработки

## Этап 2: генерация паролей — 31.10.2026

Реализовано:

- Независимый модуль generator.py: неизменяемые настройки, проверка входа,
  secrets и отбрасывание кандидатов без обязательных групп.
- В окне: длина 4–128, четыре группы, генерация, показ/скрытие и копирование.
- Новый результат скрыт; при ошибке старый очищается, копирование отключается.
- Обновлены инструкции. Внешние зависимости не потребовались.

Фактически проверено:

- Шесть автоматических тестов прошли. Включены все 15 непустых сочетаний групп
  на длинах 4, 16, 128 по восемь повторений (360 результатов), ошибки длины,
  типов и переключателей, отсутствие групп, контролируемое отбрасывание кандидата.
- Компиляция с предупреждениями как ошибками прошла.
- В настоящем окне проверены генерация кнопкой, видимость, повторное скрытие,
  некорректный ввод, цифры длиной 128, пустой набор групп и размер 640×620.
- Обработчик копирования и его ошибка проверены с подменой операций буфера.
  Реальный системный буфер не изменялся; вставка в другое приложение не проверялась.
- Первая проверка компоновки выявила нехватку высоты при 640×540;
  минимальный размер исправлен, повторная проверка успешна.

Пользователь подтвердил читаемость и запуск первого этапа. Для второго этапа
остались ручная проверка внешнего вида, реальное копирование и вставка,
управление настройками мышью и клавиатурой.

Следующий этап: формализация правил оценки сложности, базовый алгоритм,
улучшение с ИИ на искусственных примерах и тесты.

## Этап 1: основа приложения — 31.10.2026

Реализовано:

- Пакет password_generator и точка входа main.py.
- Главное окно Tkinter с вводной информацией, планом и кнопкой закрытия.
- Подробные русские docstring и комментарии, правила разработки в AGENTS.md.
- Локальное виртуальное окружение .venv и README с командами запуска.
- .gitignore: окружение, временные файлы и локальные секреты исключаются; документация остаётся.

Фактически проверено на Windows:

- Python 3.14.10 (64-bit), Tkinter 9.0, pip 26.2.2 в окружении проекта.
- Компиляция main.py и пакета с превращением предупреждений в ошибки: успешно.
- Импорт main без создания окна: успешно.
- Создание настоящего окна: успешно; начальный размер 760×500.
- Изменение до минимального размера 640×440: успешно; запрошенный размер контейнера укладывается в доступную область.
- Запуск цикла событий и программное нажатие кнопки «Закрыть»: успешно, процесс завершился без ошибки.

Осталось проверить пользователю: читаемость русского текста и масштабирование
на своём экране, изменение размера мышью, закрытие крестиком. Визуальная
проверка по снимку экрана на этом этапе не выполнялась.

При настройке системный ярлык python оказался неработающим. Использован
установленный Python по прямому пути, затем создано окружение проекта.
Первоначальная установка pip потребовала разрешения на доступ к временной папке;
повторное создание окружения с разрешением завершилось успешно.

Функции генерации, оценки и хранения ещё отсутствуют. Следующий этап:
настройки длины и групп символов, генератор на secrets и содержательные
автоматические проверки его правил.
