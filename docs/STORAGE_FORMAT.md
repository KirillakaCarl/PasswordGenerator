# Хранилище: формат 1

Дата: 31.10.2026. Реализация: encryption.py, storage.py и storage_ui.py.
Внешняя зависимость: cryptography 50.0.2, проверена с Python 3.14.10 / Windows.

## Мастер-пароль и ключ

Мастер-пароль — отдельная строка 12–1024 символа, без обрезания пробелов.
Из него библиотечный Argon2id получает 32 байта ключа: 3 прохода, 4 линии,
65536 КиБ памяти (64 МиБ), случайная 16-байтовая соль на каждый новый файл.
Замер на целевом компьютере: примерно 0,045 секунды на получение ключа;
это единичный замер, а не гарантия скорости на других устройствах.
Ключ кодируется URL-safe Base64 для Fernet, а не сохраняется на диск.

Профиль параметров фиксирован. Файл с другими значениями отклоняется
до вычисления ключа; алгоритм не ослабляется автоматически ради совместимости.

## Открытый заголовок

JSON UTF-8 содержит ровно поля:

| Поле | Содержимое |
| --- | --- |
| version | целое число 1 |
| cipher | строка fernet |
| kdf | имя argon2id и фиксированные параметры length/iterations/lanes/memory_cost |
| salt | 16 байт в Base64 |
| token | токен Fernet в Base64 |

Проверяются размер до 5 МиБ, типы, версия, набор полей, соль и профиль ключа.
Повторяющиеся ключи JSON запрещены. Затем Fernet проверяет подлинность токена
и расшифровывает полезную нагрузку. Неверный мастер-пароль и повреждение
токена дают одинаковое сообщение. Отсутствующий файл и ошибка доступа
обрабатываются как ошибка чтения/записи.

## Зашифрованная полезная нагрузка

JSON-объект с version=1 и entries — списком записей. Каждая запись содержит:

- id: уникальный канонический UUID;
- title: название 1–100 символов, без крайних пробелов;
- password: строку 1–1024 символа, без изменения пробелов и регистра;
- created_at: ISO 8601 с часовым поясом; при создании записывается UTC.

Названия и пароли шифруются вместе. Одинаковые названия разрешены.
После расшифрования схема, поля, ID, дата и строки проверяются заново.

## Сохранение

Новый список записей сначала сериализуется и шифруется целиком. Только
зашифрованные байты записываются во временный файл того же каталога.
После flush и fsync:

- создание использует os.link: новое имя публикуется без возможности
  заменить существующий файл даже при гонке между проверкой и записью;
- обновление использует os.replace: целевой файл заменяется атомарно.

После успешной операции обновляется список в памяти. Отказ записи до замены
сохраняет прежний файл и сеанс. Временный файл удаляется при обычном завершении
и обработанной ошибке. При аварийном завершении процесса временный файл
может остаться, но он содержит только шифротекст.

Создание проверено на NTFS. Файловая система должна поддерживать жёсткие
ссылки; обхода через неатомарную перезапись на несовместимых носителях нет.
Формат предназначен для небольшого локального хранилища, без одновременной
записи из нескольких экземпляров и без гарантии сохранения при отказе диска.

## Ограничения

Нет восстановления и смены мастер-пароля, облачной синхронизации и встроенной
резервной копии. Отсутствует защита от вредоносных программ на компьютере.
Размер файла, открытые метаданные и время токена Fernet видимы снаружи.
При блокировке удаляются ссылки на ключ и записи, но полное обнуление памяти
Python не гарантируется. Буфер обмена остаётся под управлением пользователя.
