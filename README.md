# PasswordGenerator

Текущая версия: **0.2.0-beta.1**, изменения объединены в `main` через PR #1.
Первая бета **0.1.0-beta.1** доступна по метке `v0.1.0-beta.1`.
История изменений находится в `CHANGELOG.md`.

Учебный проект по кейсу № 8: генератор случайных паролей с оценкой сложности.
Программа обучения: «Python-разработчик с использованием инструментов ИИ».

## Текущее состояние

Этап 3: работает генерация с выбором длины 4–128 и групп символов.
Каждый пароль содержит все выбранные группы и не содержит символов остальных.
Есть переключатель видимости, копирование и сообщения об ошибках.
Добавлены автоматическая оценка результата и ручная оценка во второй вкладке.
Зашифрованное хранилище пока не реализовано.

Приложение на текущем этапе использует только стандартную библиотеку Python,
не обращается к сети и не создаёт пользовательские хранилища.

## Требования

- Windows с Python 3.12 или новее и установленным Tkinter.
- Проверенное локальное окружение: Python 3.14.10 (64-bit), Tkinter 9.0.
- Для текущего этапа внешние пакеты не требуются.

Виртуальное окружение `.venv` создаётся один раз на каждом компьютере и не
публикуется в Git. Активация окружения необязательна: команды ниже явно
используют Python из него и не требуют менять политику выполнения PowerShell.

## Подготовка и запуск в PowerShell

Откройте терминал в папке проекта. Если команда `python` запускает установленный
Python, создайте окружение:

```powershell
python -m venv .venv
```

На компьютере автора системный ярлык `python` не работает; проверенный вариант:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python314\python.exe" -m venv .venv
```

На другом компьютере путь зависит от установки Python. Проверить его можно
командой `python --version` или `py --version`. Если Python установлен без
Tkinter, добавьте компонент Tcl/Tk через установщик Python.

Запуск из папки проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

После появления окна его можно закрыть кнопкой «Закрыть» или крестиком.
На текущем этапе `requirements.txt` содержит только пояснения; установка
внешних зависимостей понадобится на этапе шифрования.

## Как создать пароль

1. Задайте длину от 4 до 128 (по умолчанию 16).
2. Выберите хотя бы одну группу: строчные или прописные латинские буквы,
   цифры, специальные символы. По умолчанию включены все четыре.
3. Нажмите «Сгенерировать». Результат появится скрытым; переключатель
   «Показать пароль» позволяет прочитать его. Длинную строку можно прокручивать в поле.
4. При необходимости нажмите «Копировать» и вставьте пароль в нужное приложение.

Пароли не сохраняются в файл. Буфер обмена доступен другим программам и
автоматически не очищается. Новая генерация заменяет предыдущий результат
и снова скрывает его. Ошибка настроек очищает результат и отключает копирование.
Изменение настроек само по себе не создаёт новый пароль: нажмите кнопку генерации.

## Как оценить пароль

После генерации категория и балл появляются под результатом, а пояснения —
во вкладке «Оценка сложности». Там же можно ввести свою строку и нажать «Оценить».
Ввод изначально скрыт; переключатель «Показать ввод» меняет его видимость.
Изменение ввода сбрасывает предыдущую оценку до повторного нажатия кнопки.

Оценка учитывает длину, группы символов и некоторые шаблоны. Порог слабой
категории — меньше 40 баллов, средней — 40–74, сильной — 75–100.
Дополнительные ограничения за короткую длину и шаблоны описаны в
`docs/ASSESSMENT_RULES.md`. Пробелы не обрезаются, Unicode учитывается.
Для пустого ввода предлагается ввести пароль; максимум — 1024 символа.

Это учебная эвристика: она не проверяет утечки, все словари или личные данные,
не гарантирует стойкость и не прогнозирует время взлома. Пароли обрабатываются
локально. Документированное применение ИИ при разработке: `docs/AI_USAGE.md`.

## Проверка приложения

Проверка синтаксиса и импорта без открытия окна:

```powershell
.\.venv\Scripts\python.exe -m compileall -q main.py password_generator
.\.venv\Scripts\python.exe -c "import main; print('Импорт выполнен без открытия окна')"
```

Автоматические тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Ручная проверка: запустить приложение, изменить длину и группы, сгенерировать
пароль, показать его, скопировать и вставить в пустой редактор. Проверить длины
4 и 128, ввод `abc`, отключение всех групп, изменение размера и закрытие окна.
Используйте только учебные пароли для проверки вставки.
Во второй вкладке сравните `Password123!` и `V7!mQ2#zR9@k`, измените ввод,
проверьте сброс оценки, пустую строку и строку с пробелами.
Результаты фактически выполненных проверок находятся в `docs/PROGRESS.md`.
