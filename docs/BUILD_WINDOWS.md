# Самостоятельное приложение Windows: 1.0.0

## Что передавать пользователю

`dist/PasswordGenerator-1.0.0-windows-x64.zip` — переносной комплект.
Распаковать целиком в обычную папку и запустить exe двойным щелчком.
Установка Python, pip и библиотек на компьютере пользователя не нужна.
Необходимо Windows x64 и доступ к временной папке; для создания хранилища
нужен диск, поддерживающий жёсткие ссылки (проверено на NTFS).

Состав:

- PasswordGenerator-1.0.0-windows-x64.exe — приложение с ресурсом версии 1.0.0.
- START_HERE.txt — краткая инструкция на русском.
- BUILD_INFO.json — версии инструментов и SHA-256 исходных файлов сборки.
- SHA256SUMS.txt — контрольная сумма exe.
- THIRD_PARTY_LICENSES/ — тексты лицензий поставляемых компонентов.

Программа работает локально, без установки и без запросов к ИИ или внешним API.
One-file сборка при запуске извлекает собственные библиотеки во временный
каталог. Данные пользователя туда не сохраняются: путь к `.vault` выбирается
отдельно. Комплект предназначен для Windows x64; для других ОС нужна своя сборка.

## Как повторить сборку из исходного кода

Из корня проекта после создания `.venv`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -v
.\.venv\Scripts\python.exe scripts/build_windows.py
```

Сборщик пишет только в build/ и dist/. Эти папки исключены из Git.
Пересборка заменяет файлы сборки с тем же именем; пользовательские хранилища
не добавляются в архив. PyInstaller и его набор hooks зафиксированы по версиям.
BUILD_INFO дополнительно записывает фактически установленные версии.

## Проверка именно exe

Служебный режим запускает окно скрыто и работает только с искусственным
хранилищем во временном каталоге. Итоговый JSON содержит признаки успеха,
но не пароли и не ключи:

```powershell
$taskReport = Join-Path $env:TEMP 'passwordgenerator-check.json'
$taskExe = (Resolve-Path '.\dist\PasswordGenerator-1.0.0-windows-x64.exe').Path
$taskProcess = Start-Process -FilePath $taskExe -ArgumentList @('--self-check', "`"$taskReport`"") -WindowStyle Hidden -Wait -PassThru
$taskProcess.ExitCode
Get-Content -LiteralPath $taskReport -Encoding utf8
```

Ожидается код 0, поля ok=true и frozen=true. Проверяются запуск Tkinter,
генерация, оценка, получение ключа Argon2id, шифрование/открытие, поиск,
сортировка, удаление и закрытие сеанса. Проверяется загрузка cryptography
из временного комплекта PyInstaller, а не из окружения разработчика.

Контрольную сумму можно сравнить так:

```powershell
Get-FileHash -LiteralPath '.\dist\PasswordGenerator-1.0.0-windows-x64.exe' -Algorithm SHA256
```

## Что проверено и что ещё проверить

На компьютере разработки (Windows 11 x64) пройдены 47 тестов исходного кода
и проверка упакованного exe из отдельной папки с Python, исключённым из PATH,
и пустыми PYTHONHOME/PYTHONPATH. Эта проверка подтверждает самостоятельную
загрузку комплекта, но не заменяет проверку на другом физическом компьютере
или чистой виртуальной машине без установленного Python.

Перед итоговым выпуском пользователь проверяет на другом Windows x64:
обычный запуск двойным щелчком, генерацию, оценку, создание учебного `.vault`,
сохранение и открытие после перезапуска, поиск и сортировку. Отдельно проверить
русские имена папок и выбранный каталог документов. Не использовать реальные
секреты для демонстрационных снимков.

Метка v1.0.0 и публикация архива как GitHub Release — отдельный этап после
проверки и самостоятельного PR пользователя. Файлы dist не коммитятся в Git.

Основание выбора упаковки: официальная документация PyInstaller:
https://pyinstaller.org/en/stable/operating-mode.html
