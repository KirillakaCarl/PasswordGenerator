# Правила оценки сложности: версия 1

Зафиксированы 31.10.2026 до реализации assessment.py. Это учебная эвристика,
а не измерение энтропии человеческого пароля или гарантия стойкости.

## Контракт

Вход: строка длиной 0–1024 символа Python. Пробелы, регистр и Unicode сохраняются.
Пустая строка даёт балл 0, категорию «Не задан» и просьбу ввести пароль.
Неправильный тип или длина свыше 1024 дают ValueError без включения ввода.
Результат не содержит сам пароль: только балл, категорию и пояснения.

## Базовая версия

Баллы: `min(60, 3 * длина) + 10 * число_групп`, максимум 100.
Группы: строчные Unicode-буквы, прописные Unicode-буквы, Unicode-цифры,
остальные символы (включая пробелы). Символ без регистра относится к остальным.
Категории: 0–39 «Слабый», 40–74 «Средний», 75–100 «Сильный».
Дополнительные ограничения длины: до 8 символов максимум 39;
от 8 до 11 максимум 74. Применяются и к улучшенной версии.

## Улучшенная версия

Начинается с базового балла. Пояснения перечисляют обнаруженные признаки.

1. Распространённый фрагмент ограничивает балл до 39. Список явно ограничен:
   password, qwerty, admin, welcome, letmein, changeme, пароль.
   Для этой проверки строка приводится к casefold; замены `@→a`, `$→s`,
   `0→o`, `1→i`, `3→e`, `4→a`, `5→s`, `7→t` помогают распознать часть
   простых подстановок; небуквенные символы затем пропускаются.
   Это только вспомогательное представление для поиска шаблонов.
2. Повтор всей строки блоком длиной от 1 до половины строки ограничивает
   балл до 39. Сравнение без учёта регистра.
3. Не более двух разных символов без учёта регистра либо доля одного
   символа не менее 50% ограничивают балл до 39.
4. Три одинаковых символа подряд ограничивают балл до 74.
5. Последовательность от четырёх символов из `abcdefghijklmnopqrstuvwxyz`,
   `0123456789`, `qwertyuiop`, `asdfghjkl`, `zxcvbnm` или обратного порядка
   уменьшает балл на 20 (один раз) и ограничивает его до 74.

Ограничения накладываются совместно, балл остаётся в пределах 0–100.
Длинная строка из цифр может не содержать распознанного шаблона; алгоритм
не проверяет утечки, персональные сведения и полный словарь. Длинная фраза
может получить высокую оценку, даже если она известная цитата. Эти ограничения
остаются частью документации и пояснения в интерфейсе.

## Основные искусственные примеры

Ожидаемая категория задаётся до запуска сравнения.

| Строка | Ожидаемая категория | Что проверяем |
| --- | --- | --- |
| password | Слабый | распространённое слово |
| Password123! | Слабый | регистр и суффикс не устраняют шаблон |
| 12345678 | Слабый | последовательность |
| aaaaaaaaaaaaaaaa | Слабый | повторы |
| Abc123!Abc123! | Слабый | повтор блока |
| V7!mQ2#zR9@k | Сильный | 12 символов без распознанного шаблона |
| sova most reka veter | Сильный | длинная учебная фраза, с оговоркой о словарях |

## Отложенные примеры

Эти примеры используются после реализации правил. Их нельзя считать
независимым исследованием: они подготовлены тем же ИИ и проверяют только
заданный контракт. Для усиления проверки полезны новые примеры пользователя.

| Строка | Ожидаемая категория |
| --- | --- |
| P@ssw0rd2026! | Слабый |
| Z9$Z9$Z9$Z9$ | Слабый |
| 987654321098 | Слабый |
| QwErTy2026! | Слабый |
| b8!Rz4@L | Средний |
| N8$wT6&rY2%p | Сильный |

Дополнительно тестируются пустой ввод, границы 7/8/11/12/1024/1025,
Unicode, пробелы, три одинаковых символа подряд и отсутствие секретов в результате.
